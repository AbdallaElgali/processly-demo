## Decisions
- **S5 is closed**: F-B15 removed the session "accepted" mark, so the Workspace and Overview read the same stored `review_action`. Confirmed in the code (no `acceptedLocally` anywhere).
- **Overview "pending" and empty/flagged rows:** the bucket precedence is unchanged (flagged, then empty, then pending/reviewed), so an empty row whose action is PENDING is "empty", while Approve's gate counts it as pending. Only the pending-vs-reviewed rule is shared, as asked.
- **Status result:** `StatusNotAppliedError` is kept for a returned status that differs from the request (defensive; it should not happen).
- **AGENTS.md:** already in `.gitignore` (`/AGENTS.md`, commit a222263); `next dev` still writes it, nothing to commit.
- **vitest 4 needed `vite` as an explicit devDependency.** Without it, npm hoisting left `@vitest/mocker` unable to resolve `vite`. A plain `npm install -D vitest@^4` crashed npm (arborist `edgesOut`); `--legacy-peer-deps` installed it, then `npm install` and `npm install -D vite@7.3.7` settled the tree.
- S2 does not make the server-side race impossible (two requests can still arrive out of order); each request now carries the latest merged values, which removes the stale-overwrite case.
